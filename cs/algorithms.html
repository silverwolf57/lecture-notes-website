CS 271 算法设计与分析 · 第 1 讲

分治与递推

分治(divide and conquer)是把问题切成同构子问题、递归求解、再合并结果的设计范式。本讲用 Karatsuba 乘法与归并排序两条线,建立"主定理"作为复杂度分析的统一工具。

1. Karatsuba 乘法

朴素 $n$ 位整数乘法需要 $\Theta(n^2)$ 次位运算。Karatsuba(1960)观察到,两个 $n$ 位整数可写成 $x = a \cdot 2^{n/2} + b$、$y = c \cdot 2^{n/2} + d$,于是 $$xy = ac \cdot 2^n + (ad + bc) \cdot 2^{n/2} + bd.$$ 直接做需要 4 次子乘法。Karatsuba 用一次加法把"中间项"化为 $(a+b)(c+d) - ac - bd$,于是只需 3 次子乘法。

记 $T(n)$ 为 Karatsuba 乘 $n$ 位数所需位运算数(忽略低阶项),则 $$T(n) = 3\,T(n/2) + \Theta(n).$$ 由主定理(情形 1,因为 $\log_2 3 \approx 1.585 > 1$),得 $T(n) = \Theta(n^{\log_2 3}) = \Theta(n^{1.585})$。 

def karatsuba(x: int, y: int) -> int:
    if x < 10 or y < 10:
        return x * y
    n = max(x.bit_length(), y.bit_length())
    half = (n + 1) // 2
    a, b = divmod(x, 1 << half)
    c, d = divmod(y, 1 << half)
    ac = karatsuba(a, c)
    bd = karatsuba(b, d)
    abcd = karatsuba(a + b, c + d)
    return (ac << (2 * half)) + ((abcd - ac - bd) << half) + bd

2. 归并排序与最坏情况界

归并排序的递推是教科书上最干净的: $$T(n) = 2\,T(n/2) + \Theta(n).$$ 由主定理(情形 2),$T(n) = \Theta(n \log n)$。这是一个最坏情况界——与输入分布无关。

定理 2.1比较排序下界

任何基于元素两两比较的排序算法,最坏情况下至少需要 $\Omega(n \log n)$ 次比较。

证明要点:决策树有 $n!$ 个叶节点(对应所有 $n!$ 种排列);高度为 $h$ 的二叉树至多有 $2^h$ 个叶节点;故 $h \ge \log_2 n! = \Omega(n \log n)$。

3. 主定理

定理 2.2主定理

设 $T(n) = a\,T(n/b) + f(n)$,$a \ge 1$、$b > 1$ 为常数。比较 $f(n)$ 与 $n^{\log_b a}$:

  1. 若 $f(n) = O(n^{\log_b a - \varepsilon})$,则 $T(n) = \Theta(n^{\log_b a})$。
  2. 若 $f(n) = \Theta(n^{\log_b a} \log^k n)$,则 $T(n) = \Theta(n^{\log_b a} \log^{k+1} n)$。
  3. 若 $f(n) = \Omega(n^{\log_b a + \varepsilon})$ 且 $a f(n/b) \le c f(n)$ 对某 $c < 1$,则 $T(n) = \Theta(f(n))$。

4. 动态规划一瞥:最长公共子序列

给定字符串 $X[1..m]$、$Y[1..n]$,LCS 长度 $\mathrm{LCS}(i, j)$ 满足 $$\mathrm{LCS}(i, j) = \begin{cases} 0 & \text{if } i = 0 \text{ or } j = 0,\\ \mathrm{LCS}(i-1, j-1) + 1 & \text{if } X_i = Y_j,\\ \max\{\mathrm{LCS}(i-1, j),\, \mathrm{LCS}(i, j-1)\} & \text{otherwise}. \end{cases}$$ 时间 $O(mn)$,空间可压到 $O(\min(m, n))$。

5. 随机化:QuickSort 的期望复杂度

随机选 pivot 的 QuickSort 满足 $$\mathbb{E}[T(n)] \le 2n \log n.$$ 关键观察:每次"枢轴比较"恰好发生一次,故总比较次数 $\le 2 \sum_{i=1}^{n-1} \mathrm{(枢轴 i 与 j 之间的对)}$,而该对被比较的概率为 $\frac{2}{j - i + 1}$。 

import random
def quicksort(a, lo=0, hi=None):
    if hi is None:
        hi = len(a) - 1
    while lo < hi:
        # 三数取中 + 随机扰动,降低最坏情况概率
        pivot = a[random.randint(lo, hi)]
        i, j = lo, hi
        while i <= j:
            while a[i] < pivot: i += 1
            while a[j] > pivot: j -= 1
            if i <= j:
                a[i], a[j] = a[j], a[i]
                i += 1; j -= 1
        if j - lo < hi - i:
            quicksort(a, lo, j)
            lo = i
        else:
            quicksort(a, i, hi)
            hi = j
