使用须知

如何阅读、引用、贡献

本页说明本站的用法、引用规范、贡献方式,以及遇到错误时怎么办。

1. 如何阅读

每篇讲义页面顶部会显示:

  • 课程编号(如 MATH 401)+ 章/节信息
  • 阅读时间(中英文加权估算)
  • 目录(章节 ≥ 4 时自动出现,右侧浮窗)
  • 顶部进度条(暗红,实时显示阅读进度)

页面右下角"↑"按钮点击回顶。键盘 Ctrl+P / ⌘+P 可打印讲义(打印版自动隐藏导航、TOC、评论等 UI 元素)。

2. 数学公式

公式用 LaTeX 语法写,KaTeX 实时渲染:

  • 行内:$x^2 + y^2 = r^2$
  • 独立行:$$ \int_a^b f(x)\,dx $$
  • 编号:在独立公式末尾加 \tag{1.1}

3. 引用本文(BibTeX)

每篇讲义底部有"📚 引用本文"展开,自动生成 BibTeX 条目。例:

@misc{wxgmath_abstract_algebra_2026,
  author       = {WXG.math},
  title        = {抽象代数 · 第 1 章 群、环、域},
  year         = {2026},
  howpublished = {GitHub Pages},
  url          = {https://silverwolf57.github.io/lecture-notes-website/math/abstract-algebra.html},
  note         = {Accessed: 2026-09-13}
}

4. 报告错误 / 提建议

所有讲义底部都有"✏️ 在 GitHub 编辑此页"链接,点进去直接编辑:

  1. 点击 → 跳到 GitHub 编辑器
  2. 改 typo、补例子、加链接
  3. 页面下方写 commit message → Propose file change
  4. 我(维护者)review 后合并

也可在每篇讲义底部的 Giscus 评论区直接留言。

5. 贡献新讲义

欢迎投递。流程:

  1. Fork 仓库
  2. 从 `math/abstract-algebra.html` 复制做模板
  3. 写讲义(遵循现有排版规范:def-box / thm-box / ex-box)
  4. 在 `index.html` 加链接,更新 `sitemap.xml` + `feed.xml`
  5. 提 Pull Request

详细见 CONTRIBUTING.md。
