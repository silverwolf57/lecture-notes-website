使用须知

如何阅读、引用、贡献

本页说明本站的用法、引用规范、贡献方式,以及遇到错误时怎么办。

1. 如何阅读

每篇讲义页面顶部会显示:

  • 章/节信息(如 抽象代数 · 第 1–4 章)
  • 下載原始 PDF(僅當作者提供 URL 時啟用)
  • 閱讀時間(中英文加權估算)
  • 目錄(章節 ≥ 4 時自動出現,右側浮窗)
  • 頂部進度條(暗紅,即時顯示閱讀進度)

页面右下角"↑"按钮点击回顶。键盘 Ctrl+P / ⌘+P 可打印讲义(打印版自动隐藏导航、TOC、评论等 UI 元素)。

2. 数学公式

公式用 LaTeX 语法写,KaTeX 实时渲染:

  • 行内:$x^2 + y^2 = r^2$
  • 独立行:$$ \int_a^b f(x)\,dx $$
  • 编号:在独立公式末尾加 \tag{章.節.序},例如 \tag{1.1.1}、\tag{2.3.5}(三級制,跨章不撞)。

3. 排版風格

本站在瀏覽器中盡量還原 LaTeX 排版感:

  • 主字型優先用 Latin Modern Roman(LaTeX 的 Computer Modern 的官方名稱;裝了 TeX Live 的讀者自動啟用),否則降級到 Charter / Iowan / Georgia 等學術襯線字; 中文用 思源宋體 / Noto Serif CJK SC / 宋體。
  • 數學公式由 KaTeX 渲染,字型與正文一致(像讀 PDF)。
  • 定理 / 定義 / 例的環境採用 LaTeX 預設樣式:粗體標籤、無方框邊界、 適當留白(.def-box / .thm-box / .ex-box)。 證明結尾用 $\square$。
  • 想對照原稿?部分講義頁頂有「📥 下載原始 PDF」按鈕(若作者提供 URL)。 為避免原稿被公開,本站不內嵌 PDF,讀者按鈕打開作者指定的外部連結。

4. 引用本文(BibTeX)

每篇讲义底部有"📚 引用本文"展开,自动生成 BibTeX 条目。例:

@misc{wxgmath_abstract_algebra_2026,
  author       = {WXG.math},
  title        = {抽象代数 · 第 1–4 章 群环域 / 唯一分解整环 / 域扩张 / 群论初步},
  year         = {2026},
  howpublished = {GitHub Pages},
  url          = {https://silverwolf57.github.io/lecture-notes-website/math/abstract-algebra.html},
  note         = {Accessed: 2026-09-13}
}

5. 报告错误 / 提建议

所有讲义底部都有"✏️ 在 GitHub 编辑此页"链接,点进去直接编辑:

  1. 点击 → 跳到 GitHub 编辑器
  2. 改 typo、补例子、加链接
  3. 页面下方写 commit message → Propose file change
  4. 我(维护者)review 后合并

也可在每篇讲义底部的 Giscus 评论区直接留言。

6. 贡献新讲义

欢迎投递。流程:

  1. Fork 仓库
  2. 从 `math/abstract-algebra.html` 复制做模板
  3. 写讲义(遵循现有排版规范:def-box / thm-box / ex-box)
  4. 在 `index.html` 加链接,更新 `sitemap.xml` + `feed.xml`
  5. 提 Pull Request

详细见 CONTRIBUTING.md。
