引论:向量范数与矩阵范数

本讲义源自中山大学数学学院(珠海)《矩阵论》课程第一章。考核方式:平时成绩 40% + 期末考试 60%,作业每周二交。

1.1 向量范数

定义 1.1向量范数

在 $\mathbb{R}^n$ 中定义一个 $n$ 元实值函数 $\|\cdot\|$,若它满足以下三个性质:

1. **非负性**:$\forall\, x \in \mathbb{R}^n$,$\|x\| \ge 0$,且 $\|x\| = 0 \iff x = 0$; 1. **齐次性**:$\forall\, \alpha \in \mathbb{R},\, x \in \mathbb{R}^n$,有 $\|\alpha x\| = |\alpha| \cdot \|x\|$; 1. **三角不等式**:$\forall\, x, y \in \mathbb{R}^n$,有 $\|x + y\| \le \|x\| + \|y\|$。

则称其为 $\mathbb{R}^n$ 中的一个**范数**。

**备注**:若存在常数 $C$,使得 $\|x + y\| \le C(\|x\| + \|y\|)$,且满足非负性与齐次性,则称其为**拟范数**,最小的 $C$ 称为**拟范数常数**。

例 1.1$p$-范数

$$\|x\|_p = \left( \sum_{i=1}^{n} |x_i|^p \right)^{1/p}\tag{1.1}$$ 当 $p \ge 1$ 时为范数;当 $0 < p < 1$ 时为拟范数。

定理 1.1

设 $A \in \mathbb{R}^{n \times n}$ 为非奇异矩阵,$\|\cdot\|$ 是 $\mathbb{R}^n$ 中的任意范数,则 $$\|x\|_A = \|Ax\|\tag{1.2}$$ 定义了 $\mathbb{R}^n$ 中的一个新范数。

定义 1.2距离

$$d(x, y) = \|x - y\|,\tag{1.3}$$ 则赋范空间是特殊的距离空间,因为范数可以导出距离。距离满足:非负、对称($d(x, y) = 0 \iff x = y$)、三角不等式。

内积空间 $\subset$ 赋范空间 $\subset$ 距离空间

其中内积空间满足 $\|x\| = \sqrt{\langle x, x \rangle}$,赋范空间满足 $d(x, y) = \|x - y\|$。

定义 1.3极限

向量 $x^* = (x_1^*, \ldots, x_n^*)^T$ 称为向量序列 $x^{(k)} = (x_1^{(k)}, \ldots, x_n^{(k)})^T$ 的**极限**,若 $x^*$ 的分量为 $x^{(k)}$ 相应分量的极限,即 $$\lim_{k \to \infty} x_i^{(k)} = x_i^*, \quad i = 1, 2, \ldots, n.\tag{1.4}$$ 记为 $x^* = \lim_{k \to \infty} x^{(k)}$。

极限满足加法、数乘运算,且范数具有连续性。

定理 1.2范数的连续性

$\mathbb{R}^n$ 中的任意范数均为 $x$ 的连续函数。

*证明.* 利用反向三角不等式 $$\big| \|x\| - \|y\| \big| \le \|x - y\|.\tag{1.5}$$ 已知 $x_k \to x$,即 $\|x_k - x\| \to 0$,则 $$0 \le \big| \|x_k\| - \|x\| \big| \le \|x_k - x\| \to 0,\tag{1.6}$$ 故 $\|x_k\| \to \|x\|$。$\square$

定理 1.3范数的等价性

在 $\mathbb{R}^n$ 中任取两个范数 $\|\cdot\|_I, \|\cdot\|_{II}$,则存在不依赖于 $x$ 的常数 $d_1, d_2$,使得 $\forall\, x \in \mathbb{R}^n$,有 $$d_1 \|x\|_I \le \|x\|_{II} \le d_2 \|x\|_I.\tag{1.7}$$

*证明.* 只需证明 $\mathbb{R}^n$ 中的任意范数 $\|\cdot\|$ 与 $\|\cdot\|_2$ 等价即可。

若存在 $c_1, c_2$ 使得 $c_1 \|x\|_2 \le \|x\|_I \le c_2 \|x\|_2$,以及 $d_1 \|x\|_2 \le \|x\|_{II} \le d_2 \|x\|_2$,则 $$\frac{d_1}{c_2} \|x\|_I \le \|x\|_{II} \le \frac{d_2}{c_1} \|x\|_I.\tag{1.8}$$

构造集合 $$S = \{ x \mid \|x\|_2 = 1, x \in \mathbb{R}^n \},\tag{1.9}$$ 则 $S$ 是 $\mathbb{R}^n$ 中的有界闭集。设 $\|\cdot\|$ 是 $\mathbb{R}^n$ 中任意范数,则其为连续函数。

由 Weierstrass 定理:$\|\cdot\|$ 在 $S$ 上可以取到极大值(记为 $d_2$)与极小值(记为 $d_1$)。

$\forall\, x \in \mathbb{R}^n,\, x \ne 0$,有 $$\left\| \frac{x}{\|x\|_2} \right\|_2 = 1 \;\Rightarrow\; \frac{x}{\|x\|_2} \in S \;\Rightarrow\; d_1 \le \left\| \frac{x}{\|x\|_2} \right\| \le d_2,\tag{1.10}$$ 从而 $$d_1 \|x\|_2 \le \|x\| \le d_2 \|x\|_2.\tag{1.11}$$ $\square$

$\mathbb{R}^n$ 中常用的范数等价关系:

- $\dfrac{1}{\sqrt{n}} \|x\|_1 \le \|x\|_2 \le \|x\|_1$,
- $\|x\|_\infty \le \|x\|_1 \le n \|x\|_\infty$,
- $\|x\|_\infty \le \|x\|_2 \le \sqrt{n} \|x\|_\infty$。

定理 1.4

向量序列 $x^{(k)} \to 0 \iff$ 对任意范数 $\|\cdot\|$,均有 $\left\| x^{(k)} \right\| \to 0$。

*证明.* ($\Rightarrow$) 由范数的连续性即得。

($\Leftarrow$) 由范数的等价性,利用无穷范数即可。$\square$

定理 1.1

$x^{(k)} \to x^* \iff$ 对任意范数 $\|\cdot\|$,有 $\left\| x^{(k)} - x^* \right\| \to 0$。

定理 1.5Cauchy 收敛准则

向量序列 $x^{(k)}$ 有极限存在 $\iff$ $x^{(k)}$ 为 Cauchy 序列,即 $$\forall\, \varepsilon > 0,\, \exists\, N \in \mathbb{N}^*,\, \text{s.t. } k, l \ge N \text{ 时, } \left\| x^{(k)} - x^{(l)} \right\| < \varepsilon,\tag{1.12}$$ 其中 $\|\cdot\|$ 为 $\mathbb{R}^n$ 中某一范数。

*证明.* 由范数的等价性,只需证明对 $\infty$-范数成立。

($\Leftarrow$) 若 $\left\| x^{(k)} - x^{(l)} \right\|_\infty = \max_{1 \le j \le n} \left| x_j^{(k)} - x_j^{(l)} \right| < \varepsilon$,则对每个 $j = 1, 2, \ldots, n$,$x_j^{(k)}$ 是 Cauchy 序列,从而 $x_j^{(k)}$ 有极限存在。因此向量序列 $x^{(k)}$ 有极限存在。

($\Rightarrow$) 若向量序列 $x^{(k)}$ 有极限存在,则每个分量 $x_j^{(k)}$ 有极限存在。于是 $$\forall\, \varepsilon > 0,\, \exists\, N_j \in \mathbb{N}^*,\, \text{s.t. } k, l \ge N_j \text{ 时, } \left| x_j^{(k)} - x_j^{(l)} \right| < \varepsilon.\tag{1.13}$$ 取 $N = \max\{N_1, N_2, \ldots, N_n\}$,则 $\forall\, k, l \ge N$,有 $$\left\| x^{(k)} - x^{(l)} \right\|_\infty < \varepsilon.\tag{1.14}$$ $\square$

1.2 矩阵范数

设 $A \in \mathbb{R}^{m \times n}$。相应于向量 $2$-范数的矩阵范数为 $$\|A\|_F = \left( \sum_{i=1}^{m} \sum_{j=1}^{n} a_{ij}^2 \right)^{1/2},\tag{2.1}$$ 称为 **Frobenius 范数**(简称 $F$-范数)。

定义 1.4矩阵范数

在 $\mathbb{R}^{m \times n}$ 中定义了一个实值函数 $\|\cdot\|$,若它满足:

1. **非负性**:$\|A\| \ge 0$,且 $\|A\| = 0 \iff A = 0$; 1. **齐次性**:$\forall\, \alpha \in \mathbb{R}$,$\|\alpha A\| = |\alpha| \cdot \|A\|$; 1. **三角不等式**:$\|A + B\| \le \|A\| + \|B\|$。

则称其为**矩阵范数**。

定义 1.5相容范数

在 $\mathbb{R}^{m \times n}, \mathbb{R}^{n \times p}, \mathbb{R}^{m \times p}$ 中分别定义了 $\|\cdot\|_u, \|\cdot\|_v, \|\cdot\|_w$。若 $$\forall\, A \in \mathbb{R}^{m \times n},\, B \in \mathbb{R}^{n \times p},\, \|AB\|_w \le \|A\|_u \|B\|_v,\tag{2.2}$$ 则称 $\|\cdot\|_v, \|\cdot\|_w$ 和 $\|\cdot\|_u$ **相容**。若 $\|\cdot\|$ 对自己相容,则称 $\|\cdot\|$ 为**相容范数**。

**备注**:有时矩阵范数的定义还包含相容范数这一条件。

定理 1.6

矩阵的 $F$-范数是相容范数,且与向量的 $2$-范数相容。

*证明.* 先证 $F$-范数与向量 $2$-范数相容。由 Cauchy 不等式, $$\|Ax\|_2^2 = \sum_{i=1}^{m} \left( \sum_{j=1}^{n} a_{ij} x_j \right)^2 \le \sum_{i=1}^{m} \left( \sum_{j=1}^{n} a_{ij}^2 \right) \left( \sum_{j=1}^{n} x_j^2 \right) = \|x\|_2^2 \cdot \sum_{i=1}^{m} \sum_{j=1}^{n} a_{ij}^2 = \|x\|_2^2 \cdot \|A\|_F^2.\tag{2.3}$$

再证 $F$-范数自身相容。设 $B = (b_1, b_2, \ldots, b_p) \in \mathbb{R}^{n \times p}$,其中 $b_j$ 为 $B$ 的列向量,则 $$\|AB\|_F^2 = \|A(b_1, b_2, \ldots, b_p)\|_F^2 = \sum_{j=1}^{p} \|Ab_j\|_2^2 \le \sum_{j=1}^{p} \|A\|_F^2 \|b_j\|_2^2 = \|A\|_F^2 \cdot \sum_{j=1}^{p} \|b_j\|_2^2 = \|A\|_F^2 \cdot \|B\|_F^2.\tag{2.4}$$

故 $F$-范数是相容范数。$\square$

定理 1.7诱导范数

设 $\|\cdot\|$ 是 $\mathbb{R}^n$ 中的范数,$\forall\, A \in \mathbb{R}^{n \times n}$,定义 $$\|A\| = \max_{\|x\| = 1} \|Ax\|,\tag{2.5}$$ 则 $\|A\|$ 是矩阵范数,称为 $\|\cdot\|$ 的**诱导范数**,且与 $\|\cdot\|$ 相容。

*证明.* 由于 $\{ x \in \mathbb{R}^n \mid \|x\| = 1 \}$ 是 $\mathbb{R}^n$ 中的有界闭集,故 $\max_{\|x\|=1} \|Ax\|$ 有意义。

**(1) 非负性**:$\|A\| \ge 0$。 $$\|A\| = 0 \iff \|Ax\| = 0,\, \forall\, \|x\| = 1 \iff Ax = 0,\, \forall\, \|x\| = 1 \iff A = 0.\tag{2.6}$$ 反之,$A = 0 \Rightarrow Ax = 0,\, \forall\, \|x\| = 1 \Rightarrow \|A\| = 0$。

**(2) 齐次性**:$\forall\, \alpha \in \mathbb{R}$, $$\|\alpha A\| = \max_{\|x\|=1} \|\alpha A x\| = |\alpha| \max_{\|x\|=1} \|Ax\| = |\alpha| \cdot \|A\|.\tag{2.7}$$

**(3) 三角不等式**: $$\|A + B\| = \max_{\|x\|=1} \|Ax + Bx\| \le \max_{\|x\|=1} \|Ax\| + \max_{\|x\|=1} \|Bx\| = \|A\| + \|B\|.\tag{2.8}$$

下面证明相容性。当 $x = 0$ 时结论显然成立。当 $x \ne 0$ 时, $$\left\| \frac{x}{\|x\|} \right\| = 1, \quad \|A\| = \max_{\|y\|=1} \|Ay\| \ge \left\| A \cdot \frac{x}{\|x\|} \right\|,\tag{2.9}$$ 故 $\|Ax\| \le \|A\| \cdot \|x\|$。进而 $$\|AB\| = \max_{\|x\|=1} \|A(Bx)\| \le \max_{\|x\|=1} \|A\| \cdot \|Bx\| = \|A\| \cdot \max_{\|x\|=1} \|Bx\| = \|A\| \cdot \|B\|.\tag{2.10}$$ $\square$

定理 1.2

对任何向量范数的诱导范数,单位阵 $I \in \mathbb{R}^{n \times n}$ 的范数为 $1$,即 $\|I\| = 1$。

**备注**:因此 $F$-范数不是诱导范数,因为 $\|I\|_F = \sqrt{n} \ne 1$(当 $n \ge 2$ 时)。

定理 1.3$1$-范数的诱导范数(列和范数)

$$\|A\|_1 = \max_{1 \le j \le n} \sum_{i=1}^{m} |a_{ij}|,\tag{2.11}$$ 称为**列和范数**。

*证明.* 当 $\|x\|_1 = 1$ 时, $$\|Ax\|_1 = \sum_{i=1}^{m} \left| \sum_{j=1}^{n} a_{ij} x_j \right| \le \sum_{i=1}^{m} \sum_{j=1}^{n} |a_{ij}| \cdot |x_j| = \sum_{j=1}^{n} |x_j| \sum_{i=1}^{m} |a_{ij}| \le \sum_{j=1}^{n} |x_j| \cdot \max_{1 \le j \le n} \sum_{i=1}^{m} |a_{ij}| = \max_{1 \le j \le n} \sum_{i=1}^{m} |a_{ij}|.\tag{2.12}$$

设 $\max_{1 \le j \le n} \sum_{i=1}^{m} |a_{ij}| = \sum_{i=1}^{m} |a_{ik}|$。构造向量 $y \in \mathbb{R}^n$: $$y_j = \begin{cases} 1, & j = k, \\ 0, & j \ne k, \end{cases}\tag{2.13}$$ 则 $\|y\|_1 = 1$,且 $$\|Ay\|_1 = \sum_{i=1}^{m} \left| \sum_{j=1}^{n} a_{ij} y_j \right| = \sum_{i=1}^{m} |a_{ik}| = \max_{1 \le j \le n} \sum_{i=1}^{m} |a_{ij}|,\tag{2.14}$$ 可以取等。因此 $$\|A\|_1 = \max_{1 \le j \le n} \sum_{i=1}^{m} |a_{ij}|.\tag{2.15}$$ $\square$

定理 1.4$\infty$-范数的诱导范数(行和范数)

$$\|A\|_\infty = \max_{1 \le i \le m} \sum_{j=1}^{n} |a_{ij}|,\tag{2.16}$$ 称为**行和范数**。

*证明.* 由诱导范数的定义, $$\|A\|_\infty = \max_{\|x\|_\infty = 1} \|Ax\|_\infty = \max_{\|x\|_\infty = 1} \max_{1 \le i \le m} \left| \sum_{j=1}^{n} a_{ij} x_j \right|.\tag{2.17}$$

当 $\|x\|_\infty = 1$ 时, $$\|Ax\|_\infty = \max_{1 \le i \le m} \left| \sum_{j=1}^{n} a_{ij} x_j \right| \le \max_{1 \le i \le m} \sum_{j=1}^{n} |a_{ij}| \cdot |x_j| \le \max_{1 \le i \le m} \sum_{j=1}^{n} |a_{ij}|.\tag{2.18}$$

下面验证可以取等。设第 $k$ 行取到最大值,即 $$\sum_{j=1}^{n} |a_{kj}| = \max_{1 \le i \le m} \sum_{j=1}^{n} |a_{ij}|.\tag{2.19}$$ 构造向量 $y \in \mathbb{R}^n$,令 $y_j = \operatorname{sgn}(a_{kj})$,即 $$y_j = \begin{cases} 1, & a_{kj} \ge 0, \\ -1, & a_{kj} < 0, \end{cases}\tag{2.20}$$ 则 $\|y\|_\infty = 1$,且 $$\|Ay\|_\infty \ge \left| \sum_{j=1}^{n} a_{kj} y_j \right| = \sum_{j=1}^{n} |a_{kj}| = \max_{1 \le i \le m} \sum_{j=1}^{n} |a_{ij}|.\tag{2.21}$$

故可以取等,从而命题得证。$\square$
