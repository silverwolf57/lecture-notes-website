向量范数与诱导矩阵范数

本章从向量范数入手,定义诱导矩阵范数与 Frobenius 范数,讨论相容性、子乘性与谱范数。

1.1 向量范数

定义 1.1.1向量范数

在 $\mathbb{R}^n$ 中定义一个 $n$ 元实值函数 $\|\cdot\|$,若它满足以下三个性质:

  1. 非负性:$\forall\, x \in \mathbb{R}^n$,$\|x\| \ge 0$,且 $\|x\| = 0 \iff x = 0$;

  2. 齐次性:$\forall\, \alpha \in \mathbb{R},\, x \in \mathbb{R}^n$,有 $\|\alpha x\| = |\alpha| \cdot \|x\|$;

  3. 三角不等式:$\forall\, x, y \in \mathbb{R}^n$,有 $\|x + y\| \le \|x\| + \|y\|$。

则称其为 $\mathbb{R}^n$ 中的一个范数。

备注:若存在常数 $C$,使得 $\|x + y\| \le C(\|x\| + \|y\|)$,且满足非负性与齐次性,则称其为拟范数,最小的 $C$ 称为拟范数常数。

例 1.1.1$p$-范数

$$\|x\|_p = \left( \sum_{i=1}^{n} |x_i|^p \right)^{1/p}\tag{1.1}$$

当 $p \ge 1$ 时为范数;当 $0 < p < 1$ 时为拟范数。

定理 1.1.1

设 $A \in \mathbb{R}^{n \times n}$ 为非奇异矩阵,$\|\cdot\|$ 是 $\mathbb{R}^n$ 中的任意范数,则

$$\|x\|_A = \|Ax\|\tag{1.2}$$

定义了 $\mathbb{R}^n$ 中的一个新范数。

定义 1.1.2距离

$$d(x, y) = \|x - y\|,\tag{1.3}$$

则赋范空间是特殊的距离空间,因为范数可以导出距离。距离满足:非负、对称($d(x, y) = 0 \iff x = y$)、三角不等式。

内积空间 $\subset$ 赋范空间 $\subset$ 距离空间 其中内积空间满足 $\|x\| = \sqrt{\langle x, x \rangle}$,赋范空间满足 $d(x, y) = \|x - y\|$。

定义 1.1.3极限

向量 $x^* = (x_1^*, \ldots, x_n^*)^T$ 称为向量序列 $x^{(k)} = (x_1^{(k)}, \ldots, x_n^{(k)})^T$ 的极限,若 $x^*$ 的分量为 $x^{(k)}$ 相应分量的极限,即

$$\lim_{k \to \infty} x_i^{(k)} = x_i^*, \quad i = 1, 2, \ldots, n.\tag{1.4}$$

记为 $x^* = \lim_{k \to \infty} x^{(k)}$。

极限满足加法、数乘运算,且范数具有连续性。

定理 1.1.2范数的连续性

$\mathbb{R}^n$ 中的任意范数均为 $x$ 的连续函数。

证明. 利用反向三角不等式

$$\big| \|x\| - \|y\| \big| \le \|x - y\|.\tag{1.5}$$

已知 $x_k \to x$,即 $\|x_k - x\| \to 0$,则

$$0 \le \big| \|x_k\| - \|x\| \big| \le \|x_k - x\| \to 0,\tag{1.6}$$

故 $\|x_k\| \to \|x\|$。$\square$

定理 1.1.3范数的等价性

在 $\mathbb{R}^n$ 中任取两个范数 $\|\cdot\|_I, \|\cdot\|_{II}$,则存在不依赖于 $x$ 的常数 $d_1, d_2$,使得 $\forall\, x \in \mathbb{R}^n$,有

$$d_1 \|x\|_I \le \|x\|_{II} \le d_2 \|x\|_I.\tag{1.7}$$

证明. 只需证明 $\mathbb{R}^n$ 中的任意范数 $\|\cdot\|$ 与 $\|\cdot\|_2$ 等价即可。

若存在 $c_1, c_2$ 使得 $c_1 \|x\|_2 \le \|x\|_I \le c_2 \|x\|_2$,以及 $d_1 \|x\|_2 \le \|x\|_{II} \le d_2 \|x\|_2$,则

$$\frac{d_1}{c_2} \|x\|_I \le \|x\|_{II} \le \frac{d_2}{c_1} \|x\|_I.\tag{1.8}$$

构造集合

$$S = \{ x \mid \|x\|_2 = 1, x \in \mathbb{R}^n \},\tag{1.9}$$

则 $S$ 是 $\mathbb{R}^n$ 中的有界闭集。设 $\|\cdot\|$ 是 $\mathbb{R}^n$ 中任意范数,则其为连续函数。

由 Weierstrass 定理:$\|\cdot\|$ 在 $S$ 上可以取到极大值(记为 $d_2$)与极小值(记为 $d_1$)。

$\forall\, x \in \mathbb{R}^n,\, x \ne 0$,有

$$\left\| \frac{x}{\|x\|_2} \right\|_2 = 1 \;\Rightarrow\; \frac{x}{\|x\|_2} \in S \;\Rightarrow\; d_1 \le \left\| \frac{x}{\|x\|_2} \right\| \le d_2,\tag{1.10}$$

从而

$$d_1 \|x\|_2 \le \|x\| \le d_2 \|x\|_2.\tag{1.11}$$

$\square$

$\mathbb{R}^n$ 中常用的范数等价关系:

$$\begin{aligned} &\dfrac{1}{\sqrt{n}} \|x\|_1 \le \|x\|_2 \le \|x\|_1,\\ &\|x\|_\infty \le \|x\|_1 \le n \|x\|_\infty,\\ &\|x\|_\infty \le \|x\|_2 \le \sqrt{n} \|x\|_\infty\text{。} \end{aligned}$$

定理 1.1.4

向量序列 $x^{(k)} \to 0 \iff$ 对任意范数 $\|\cdot\|$,均有 $\left\| x^{(k)} \right\| \to 0$。

证明. ($\Rightarrow$) 由范数的连续性即得。

($\Leftarrow$) 由范数的等价性,利用无穷范数即可。$\square$

命题 1.1.1

$x^{(k)} \to x^* \iff$ 对任意范数 $\|\cdot\|$,有 $\left\| x^{(k)} - x^* \right\| \to 0$。

定理 1.1.5Cauchy 收敛准则

向量序列 $x^{(k)}$ 有极限存在 $\iff$ $x^{(k)}$ 为 Cauchy 序列,即

$$\forall\, \varepsilon > 0,\, \exists\, N \in \mathbb{N}^*,\, \text{s.t. } k, l \ge N \text{ 时, } \left\| x^{(k)} - x^{(l)} \right\| < \varepsilon,\tag{1.12}$$

其中 $\|\cdot\|$ 为 $\mathbb{R}^n$ 中某一范数。

证明. 由范数的等价性,只需证明对 $\infty$-范数成立。

($\Leftarrow$) 若 $\left\| x^{(k)} - x^{(l)} \right\|_\infty = \max_{1 \le j \le n} \left| x_j^{(k)} - x_j^{(l)} \right| < \varepsilon$,则对每个 $j = 1, 2, \ldots, n$,$x_j^{(k)}$ 是 Cauchy 序列,从而 $x_j^{(k)}$ 有极限存在。因此向量序列 $x^{(k)}$ 有极限存在。

($\Rightarrow$) 若向量序列 $x^{(k)}$ 有极限存在,则每个分量 $x_j^{(k)}$ 有极限存在。于是

$$\forall\, \varepsilon > 0,\, \exists\, N_j \in \mathbb{N}^*,\, \text{s.t. } k, l \ge N_j \text{ 时, } \left| x_j^{(k)} - x_j^{(l)} \right| < \varepsilon.$$

取 $N = \max\{N_1, N_2, \ldots, N_n\}$,则 $\forall\, k, l \ge N$,有

$$\left\| x^{(k)} - x^{(l)} \right\|_\infty < \varepsilon.$$

$\square$

1.2 矩阵范数

设 $A \in \mathbb{R}^{m \times n}$。相应于向量 $2$-范数的矩阵范数为 $$\|A\|_F = \left( \sum_{i=1}^{m} \sum_{j=1}^{n} a_{ij}^2 \right)^{1/2},\tag{2.1}$$

称为 Frobenius 范数(简称 $F$-范数)。

定义 1.2.1矩阵范数

在 $\mathbb{R}^{m \times n}$ 中定义了一个实值函数 $\|\cdot\|$,若它满足:

  1. 非负性:$\|A\| \ge 0$,且 $\|A\| = 0 \iff A = 0$;

  2. 齐次性:$\forall\, \alpha \in \mathbb{R}$,$\|\alpha A\| = |\alpha| \cdot \|A\|$;

  3. 三角不等式:$\|A + B\| \le \|A\| + \|B\|$。

则称其为矩阵范数。

定义 1.2.2相容范数

在 $\mathbb{R}^{m \times n}, \mathbb{R}^{n \times p}, \mathbb{R}^{m \times p}$ 中分别定义了 $\|\cdot\|_u, \|\cdot\|_v, \|\cdot\|_w$。若

$$\forall\, A \in \mathbb{R}^{m \times n},\, B \in \mathbb{R}^{n \times p},\, \|AB\|_w \le \|A\|_u \|B\|_v,\tag{2.2}$$

则称 $\|\cdot\|_v, \|\cdot\|_w$ 和 $\|\cdot\|_u$ 相容。若 $\|\cdot\|$ 对自己相容,则称 $\|\cdot\|$ 为相容范数。

备注:有时矩阵范数的定义还包含相容范数这一条件。

定理 1.2.1

矩阵的 $F$-范数是相容范数,且与向量的 $2$-范数相容。

证明. 先证 $F$-范数与向量 $2$-范数相容。由 Cauchy 不等式,

$$\|Ax\|_2^2 = \sum_{i=1}^{m} \left( \sum_{j=1}^{n} a_{ij} x_j \right)^2 \le \sum_{i=1}^{m} \left( \sum_{j=1}^{n} a_{ij}^2 \right) \left( \sum_{j=1}^{n} x_j^2 \right) = \|x\|_2^2 \cdot \sum_{i=1}^{m} \sum_{j=1}^{n} a_{ij}^2 = \|x\|_2^2 \cdot \|A\|_F^2.\tag{2.3}$$

再证 $F$-范数自身相容。设 $B = (b_1, b_2, \ldots, b_p) \in \mathbb{R}^{n \times p}$,其中 $b_j$ 为 $B$ 的列向量,则

$$\|AB\|_F^2 = \|A(b_1, b_2, \ldots, b_p)\|_F^2 = \sum_{j=1}^{p} \|Ab_j\|_2^2 \le \sum_{j=1}^{p} \|A\|_F^2 \|b_j\|_2^2 = \|A\|_F^2 \cdot \sum_{j=1}^{p} \|b_j\|_2^2 = \|A\|_F^2 \cdot \|B\|_F^2.\tag{2.4}$$

故 $F$-范数是相容范数。$\square$

定理 1.2.2诱导范数

设 $\|\cdot\|$ 是 $\mathbb{R}^n$ 中的范数,$\forall\, A \in \mathbb{R}^{n \times n}$,定义

$$\|A\| = \max_{\|x\| = 1} \|Ax\|,\tag{2.5}$$

则 $\|A\|$ 是矩阵范数,称为 $\|\cdot\|$ 的诱导范数,且与 $\|\cdot\|$ 相容。

证明. 由于 $\{ x \in \mathbb{R}^n \mid \|x\| = 1 \}$ 是 $\mathbb{R}^n$ 中的有界闭集,故 $\max_{\|x\|=1} \|Ax\|$ 有意义。

(1) 非负性:$\|A\| \ge 0$。

$$\|A\| = 0 \iff \|Ax\| = 0,\, \forall\, \|x\| = 1 \iff Ax = 0,\, \forall\, \|x\| = 1 \iff A = 0.\tag{2.6}$$

反之,$A = 0 \Rightarrow Ax = 0,\, \forall\, \|x\| = 1 \Rightarrow \|A\| = 0$。

(2) 齐次性:$\forall\, \alpha \in \mathbb{R}$,

$$\|\alpha A\| = \max_{\|x\|=1} \|\alpha A x\| = |\alpha| \max_{\|x\|=1} \|Ax\| = |\alpha| \cdot \|A\|.\tag{2.7}$$

(3) 三角不等式:

$$\|A + B\| = \max_{\|x\|=1} \|Ax + Bx\| \le \max_{\|x\|=1} \|Ax\| + \max_{\|x\|=1} \|Bx\| = \|A\| + \|B\|.\tag{2.8}$$

下面证明相容性。当 $x = 0$ 时结论显然成立。当 $x \ne 0$ 时,$\|x/\|x\|\| = 1$,$\|A\| = \max_{\|y\|=1} \|Ay\| \ge \|A \cdot x/\|x\|\|$,故 $\|Ax\| \le \|A\| \cdot \|x\|$。进而

$$\|AB\| = \max_{\|x\|=1} \|A(Bx)\| \le \max_{\|x\|=1} \|A\| \cdot \|Bx\| = \|A\| \cdot \max_{\|x\|=1} \|Bx\| = \|A\| \cdot \|B\|.\tag{2.10}$$

$\square$

命题 1.2.1

对任何向量范数的诱导范数,单位阵 $I \in \mathbb{R}^{n \times n}$ 的范数为 $1$,即 $\|I\| = 1$。

备注:因此 $F$-范数不是诱导范数,因为 $\|I\|_F = \sqrt{n} \ne 1$(当 $n \ge 2$ 时)。

命题 1.2.2$1$-范数的诱导范数(列和范数)

$$\|A\|_1 = \max_{1 \le j \le n} \sum_{i=1}^{m} |a_{ij}|,\tag{2.11}$$

称为列和范数。

证明. 当 $\|x\|_1 = 1$ 时,

$$\|Ax\|_1 = \sum_{i=1}^{m} \left| \sum_{j=1}^{n} a_{ij} x_j \right| \le \sum_{i=1}^{m} \sum_{j=1}^{n} |a_{ij}| \cdot |x_j| = \sum_{j=1}^{n} |x_j| \sum_{i=1}^{m} |a_{ij}| \le \sum_{j=1}^{n} |x_j| \cdot \max_{1 \le j \le n} \sum_{i=1}^{m} |a_{ij}| = \max_{1 \le j \le n} \sum_{i=1}^{m} |a_{ij}|.\tag{2.12}$$

设 $\max_{1 \le j \le n} \sum_{i=1}^{m} |a_{ij}| = \sum_{i=1}^{m} |a_{ik}|$。构造向量 $y \in \mathbb{R}^n$:$y_j = 1$ 当 $j = k$,否则 $y_j = 0$,则 $\|y\|_1 = 1$,且

$$\|Ay\|_1 = \sum_{i=1}^{m} \left| \sum_{j=1}^{n} a_{ij} y_j \right| = \sum_{i=1}^{m} |a_{ik}| = \max_{1 \le j \le n} \sum_{i=1}^{m} |a_{ij}|,\tag{2.14}$$

可以取等。因此 $\|A\|_1 = \max_{1 \le j \le n} \sum_{i=1}^{m} |a_{ij}|$。$\square$

命题 1.2.3$\infty$-范数的诱导范数(行和范数)

$$\|A\|_\infty = \max_{1 \le i \le m} \sum_{j=1}^{n} |a_{ij}|,\tag{2.16}$$

称为行和范数。

证明. 由诱导范数的定义,

$$\|A\|_\infty = \max_{\|x\|_\infty = 1} \|Ax\|_\infty = \max_{\|x\|_\infty = 1} \max_{1 \le i \le m} \left| \sum_{j=1}^{n} a_{ij} x_j \right|.\tag{2.17}$$

当 $\|x\|_\infty = 1$ 时,

$$\|Ax\|_\infty = \max_{1 \le i \le m} \left| \sum_{j=1}^{n} a_{ij} x_j \right| \le \max_{1 \le i \le m} \sum_{j=1}^{n} |a_{ij}| \cdot |x_j| \le \max_{1 \le i \le m} \sum_{j=1}^{n} |a_{ij}|.\tag{2.18}$$

下面验证可以取等。设第 $k$ 行取到最大值,即 $\sum_{j=1}^{n} |a_{kj}| = \max_{1 \le i \le m} \sum_{j=1}^{n} |a_{ij}|$。构造向量 $y \in \mathbb{R}^n$,令 $y_j = \operatorname{sgn}(a_{kj})$,则 $\|y\|_\infty = 1$,且

$$\|Ay\|_\infty \ge \left| \sum_{j=1}^{n} a_{kj} y_j \right| = \sum_{j=1}^{n} |a_{kj}| = \max_{1 \le i \le m} \sum_{j=1}^{n} |a_{ij}|.\tag{2.21}$$

故可以取等,从而命题得证。$\square$

定理 1.2.3矩阵 $2$-范数与谱半径

$$\|A\|_2 = \sqrt{\rho(A^TA)},$$

其中 $\rho(A) = \max\limits_{1 \le i \le n} |\lambda_i|$ 称为矩阵的谱半径。

证明.

$$\|A\|_2^2 = \max_{\|x\|_2=1} \|Ax\|_2^2 = \max_{\|x\|_2=1} (Ax, Ax) = \max_{\|x\|_2=1} (A^TA x, x) = \max_{\|x\|_2=1} x^T (A^TA) x.$$

设 $A^TA$ 的全部特征值为 $\lambda_1 \ge \lambda_2 \ge \cdots \ge \lambda_n \ge 0$(因为 $A^TA$ 对称半正定),相应的标准正交特征向量为 $y_1, y_2, \dots, y_n$。

$\forall z \in \mathbb{R}^n,\, \|z\|_2 = 1$,设 $z = c_1 y_1 + c_2 y_2 + \cdots + c_n y_n$,则 $c_1^2 + c_2^2 + \cdots + c_n^2 = 1$。于是

$$z^T A^T A z = z^T A^T A (c_1 y_1 + c_2 y_2 + \cdots + c_n y_n) = \sum_{i=1}^n c_i^2 \lambda_i \le \lambda_1 \sum_{i=1}^n c_i^2 = \lambda_1.$$

取 $z = y_1$,有 $y_1^T A^T A y_1 = \lambda_1$,可以取等。从而命题得证。$\square$

备注:当 $A$ 是对称矩阵时,$A^TA = A^2$,$\rho(A^TA) = \rho^2(A)$,此时 $\|A\|_2 = \rho(A)$。

定理 1.2.4正交不变性

矩阵的 $2$-范数和 $F$-范数都具有正交不变性,即 $\forall$ 正交矩阵 $U \in \mathbb{R}^{m \times m}$,$V \in \mathbb{R}^{n \times n}$,有

$$\|UAV\|_2 = \|A\|_2, \qquad \|UAV\|_F = \|A\|_F.$$

证明.

$$\|UAV\|_2^2 = \lambda_{\max}(V^T A^T U^T U A V) = \lambda_{\max}(V^T A^T A V) = \lambda_{\max}(A^TA) = \|A\|_2^2.$$$$\|UAV\|_F^2 = \operatorname{tr}(V^T A^T U^T U A V) = \operatorname{tr}(V^T A^T A V) = \sum_{i=1}^n \lambda_i(A^TA) = \operatorname{tr}(A^TA) = \|A\|_F^2.$$

$\square$

矩阵范数的等价关系:设 $A \in \mathbb{R}^{m \times n}$,则

$$\|A\|_2 \le \|A\|_F \le \sqrt{n}\, \|A\|_2$$$$\frac{1}{\sqrt{n}} \|A\|_\infty \le \|A\|_2 \le \sqrt{m}\, \|A\|_\infty$$$$\frac{1}{\sqrt{m}} \|A\|_1 \le \|A\|_2 \le \sqrt{n}\, \|A\|_1$$

定理 1.2.5谱半径与相容范数

矩阵 $A \in \mathbb{R}^{n \times n}$ 的所有相容范数以 $\rho(A)$ 为其下界。

证明. 设 $\lambda$ 为 $A$ 的特征值,满足 $|\lambda| = \max_{1 \le i \le n} |\lambda_i| = \rho(A)$,设相应于 $\lambda$ 的特征向量为 $x$。则

$$\|Ax\| = \|\lambda x\| = |\lambda| \|x\| \le \|A\| \|x\|,$$

故 $|\lambda| \le \|A\|$,即 $\rho(A) \le \|A\|$。$\square$

定理 1.2.6谱半径是相容范数的下确界

矩阵 $A \in \mathbb{R}^{n \times n}$ 的所有相容范数以 $\rho(A)$ 为其下确界。

证明. 只需证 $\forall \varepsilon > 0$,$\exists \|\cdot\|$,s.t. $\|A\| \le \rho(A) + \varepsilon$。

$\varepsilon$-Jordan 标准形:$\forall \varepsilon > 0$,令 $\tilde A = \dfrac{1}{\varepsilon} A$。设 $\tilde A$ 的 Jordan 分解为 $P\tilde A P^{-1} = J$(分块 Jordan)。则 $PAP^{-1} = \varepsilon J$,且 $\varepsilon J_i$ 的次对角线元素均为 $\varepsilon$。故 $\|PAP^{-1}\|_\infty \le \rho(A) + \varepsilon$。

现证明 $\|PAP^{-1}\|_\infty$ 是 $A$ 的一个相容范数。对 $\mathbb{R}^n$ 中的任意范数 $\|\cdot\|$,$P$ 非奇异,则 $\|x\|_p = \|Px\|$ 是 $\mathbb{R}^n$ 中的范数,它诱导出的矩阵范数为

$$\max_{\|x\|_p=1} \|Ax\|_p = \max_{\|Px\|=1} \|PAx\| = \max_{\|Px\|=1} \|PAP^{-1} Px\| = \max_{\|y\|=1} \|PAP^{-1} y\| = \|PAP^{-1}\|.$$

$\square$

命题 1.2.4

若 $\rho(A) < 1$,则存在 $A$ 的一种相容范数 $\|A\|$,s.t. $\|A\| < 1$。

证明. 取 $\varepsilon = \dfrac{1 - \rho(A)}{2}$,由 Thm 1.2.6 即可得证。$\square$

矩阵序列的收敛性

定理 1.2.7

$\forall A \in \mathbb{R}^{n \times n}$,$A^k \to 0 \iff \rho(A) < 1$。

证明. ($\Leftarrow$) 若 $\rho(A) < 1$,则由 Prop 1.2.4,$\exists A$ 的一种相容范数,s.t. $\|A\| < 1$。于是

$$\|A^k\| \le \|A\|^k \to 0,$$

故 $A^k \to 0$。

($\Rightarrow$) 若 $A^k \to 0$,假设 $\rho(A) \ge 1$,则 $A$ 有特征值 $\lambda$ 满足 $|\lambda| \ge 1$。设 $\lambda$ 对应的特征向量为 $x$,则

$$A^k x = \lambda^k x \not\to 0,$$

与 $A^k \to 0$ 矛盾。故假设不成立,即 $\rho(A) < 1$。$\square$

定理 1.2.8矩阵幂级数

矩阵幂级数 $I + A + \cdots + A^k + \cdots$ 收敛 $\iff$ $\rho(A) < 1$,当其收敛时,

$$\sum_{k=0}^{\infty} A^k = (I - A)^{-1}.$$

命题 1.2.5

设 $\|\cdot\|$ 满足 $\|I\| = 1$,若 $\|A\| < 1$,则 $I - A$ 非奇异,且

$$\|(I-A)^{-1}\| \le \frac{1}{1 - \|A\|}.$$

证明. 由 $\rho(A) \le \|A\| < 1$,故 $I - A$ 没有零特征值,即 $I - A$ 非奇异。

$$(I-A)^{-1} = I + A + A^2 + \cdots + A^k + \cdots,$$

于是

$$\|(I-A)^{-1}\| \le \|I\| + \|A\| + \cdots + \|A\|^k + \cdots = \frac{1}{1 - \|A\|}.$$

$\square$

1.3 矩阵的奇异值分解

定理 1.3.1奇异值分解定理(SVD)

设 $A \in \mathbb{R}^{m \times n}$,则存在正交矩阵 $U \in \mathbb{R}^{m \times m}$,$V \in \mathbb{R}^{n \times n}$,使得

$$U^T A V = \begin{pmatrix} \Sigma & 0 \\ 0 & 0 \end{pmatrix}_{m \times n},$$

其中 $\Sigma = \operatorname{diag}(\sigma_1, \sigma_2, \dots, \sigma_r)$,且 $\sigma_1 \ge \sigma_2 \ge \cdots \ge \sigma_r > 0$。

证明. 考虑 $A^T A \in \mathbb{R}^{n \times n}$,它对称半正定。设其特征值为

$$\sigma_1^2 \ge \sigma_2^2 \ge \cdots \ge \sigma_r^2 > 0 = \sigma_{r+1}^2 = \cdots = \sigma_n^2,$$

对应的标准正交特征向量组为 $v_1, v_2, \dots, v_n$。

令 $V_1 = (v_1, \dots, v_r)$,$V_2 = (v_{r+1}, \dots, v_n)$,并记 $V = (V_1, V_2)$。则

$$V^T A^T A V = \begin{pmatrix} \Sigma^2 & 0 \\ 0 & 0 \end{pmatrix}.$$

由右下角分块得 $V_2^T A^T A V_2 = 0$,故 $A V_2 = 0$。

由左上角分块得 $V_1^T A^T A V_1 = \Sigma^2$,于是 $\Sigma^{-1} V_1^T A^T A V_1 \Sigma^{-1} = I_r$。令 $U_1 = A V_1 \Sigma^{-1}$,则 $U_1^T U_1 = I_r$。

存在 $u_{r+1}, \dots, u_m$ 使得 $u_1, \dots, u_m$ 构成 $\mathbb{R}^m$ 的一组标准正交基。令 $U_2 = (u_{r+1}, \dots, u_m)$,$U = (U_1, U_2)$,则 $U$ 为正交矩阵。直接计算可得

$$U^T A V = \begin{pmatrix} U_1^T A V_1 & U_1^T A V_2 \\ U_2^T A V_1 & U_2^T A V_2 \end{pmatrix} = \begin{pmatrix} \Sigma & 0 \\ 0 & 0 \end{pmatrix}.$$

$\square$

命题 1.3.1

$$V^T A^T A V = \operatorname{diag}(\sigma_1^2, \sigma_2^2, \dots, \sigma_r^2, 0, \dots, 0) \in \mathbb{R}^{n \times n},$$$$U^T A A^T U = \operatorname{diag}(\sigma_1^2, \sigma_2^2, \dots, \sigma_r^2, 0, \dots, 0) \in \mathbb{R}^{m \times m}.$$

命题 1.3.2

$$A v_i = \sigma_i u_i, \qquad A^T u_i = \sigma_i v_i, \qquad i = 1, 2, \dots, r.$$

$u_i, v_i$ 分别称为 $A$ 的左、右奇异向量。

定义 1.3.1奇异值

$\sigma_1, \dots, \sigma_r, 0, \dots, 0$ 称为 $A$ 的奇异值。

备注:若 $A$ 为复矩阵,则将 $A^T A$ 替换为半正定 Hermite 矩阵,正交矩阵替换为酉矩阵即可。

定理 1.3.2极分解

设 $A \in \mathbb{R}^{n \times n}$,则存在对称半正定矩阵 $P \in \mathbb{R}^{n \times n}$ 和正交矩阵 $Q \in \mathbb{R}^{n \times n}$,使得 $A = PQ$。

证明. 由 SVD,$A = U \Sigma V^T = (U \Sigma U^T)(U V^T)$。令 $P = U \Sigma U^T$,$Q = U V^T$,则 $P$ 对称半正定,$Q$ 正交。$\square$

定理 1.3.3SVD 的性质

设 $A \in \mathbb{R}^{m \times n}$ 的 SVD 为 $U^T A V = \begin{pmatrix} \Sigma & 0 \\ 0 & 0 \end{pmatrix}$,则:

  1. $\operatorname{rank}(A) = r$;

  2. $\operatorname{Im}(A) = \operatorname{span}\{u_1, \dots, u_r\} = (\ker A^T)^\perp$;

  3. $\ker(A) = \operatorname{span}\{v_{r+1}, \dots, v_n\} = (\operatorname{Im} A^T)^\perp$;

  4. $A = \displaystyle\sum_{j=1}^r \sigma_j u_j v_j^T = U_1 \Sigma V_1^T$(薄 SVD);

  5. $\|A\|_F^2 = \sigma_1^2 + \cdots + \sigma_r^2$,$\|A\|_2 = \sigma_1$;

  6. 条件数 $k(A) = \dfrac{\sigma_1}{\sigma_r}$,用来刻画 $A$ 的病态程度,越小越良态。

证明. (1) $\operatorname{rank}(A) = \operatorname{rank} \begin{pmatrix} \Sigma & 0 \\ 0 & 0 \end{pmatrix} = r$。

(4) 由薄 SVD:

$$A = U \begin{pmatrix} \Sigma & 0 \\ 0 & 0 \end{pmatrix} V^T = (U_1, U_2) \begin{pmatrix} \Sigma & 0 \\ 0 & 0 \end{pmatrix} \begin{pmatrix} V_1^T \\ V_2^T \end{pmatrix} = U_1 \Sigma V_1^T = \sum_{j=1}^r \sigma_j u_j v_j^T.$$

(5) 由正交变换不改变 Frobenius 范数和谱范数,

$$\|A\|_F^2 = \|U^T A V\|_F^2 = \left\| \begin{pmatrix} \Sigma & 0 \\ 0 & 0 \end{pmatrix} \right\|_F^2 = \sum_{i=1}^r \sigma_i^2,$$$$\|A\|_2 = \left\| \begin{pmatrix} \Sigma & 0 \\ 0 & 0 \end{pmatrix} \right\|_2 = \sigma_1.$$

(2) $\forall x \in \operatorname{Im}(A)$,$\exists y \in \mathbb{R}^n$ 使得 $x = A y = U_1 \Sigma V_1^T y \in \operatorname{span}\{u_1, \dots, u_r\}$,故 $\operatorname{Im}(A) \subseteq \operatorname{span}\{u_1, \dots, u_r\}$。又 $\dim(\operatorname{Im} A) = \operatorname{rank}(A) = r = \dim(\operatorname{span}\{u_1, \dots, u_r\})$,故等号成立。

(3) $\forall x \in \ker(A)$,$A x = 0$,即 $U \begin{pmatrix} \Sigma & 0 \\ 0 & 0 \end{pmatrix} V^T x = 0 \implies V_1^T x = 0$。故 $x \in \operatorname{span}\{v_{r+1}, \dots, v_n\}$。反之,$\forall x \in \operatorname{span}\{v_{r+1}, \dots, v_n\}$,$V_1^T x = 0$,故 $A x = U_1 \Sigma V_1^T x = 0$。

(6) $k(A) = \|A\|_2 \|A^{-1}\|_2 = \sigma_1 \cdot \dfrac{1}{\sigma_r} = \dfrac{\sigma_1}{\sigma_r}$。

$\square$

矩阵的低秩逼近问题

设 $A \in \mathbb{R}^{m \times n}$,$\operatorname{rank}(A) = r$,求 $$\min_{\operatorname{rank}(B) \le k} \|A - B\|_2, \qquad (k < r).$$

定理 1.3.4Eckart--Young 定理

设 $A \in \mathbb{R}^{m \times n}$ 的 SVD 为 $U^T A V = \begin{pmatrix} \Sigma & 0 \\ 0 & 0 \end{pmatrix}$,$\operatorname{rank}(A) = r$。令

$$A_k = \sum_{j=1}^k \sigma_j u_j v_j^T,$$

则

$$\min_{\operatorname{rank}(B) \le k} \|A - B\|_2 = \|A - A_k\|_2 = \sigma_{k+1}.$$

证明. 由 $A_k$ 的定义,$A - A_k$ 的奇异值从第 $k+1$ 个开始保留,故 $\|A - A_k\|_2 = \sigma_{k+1}$。

下证 $\forall B \in \mathbb{R}^{m \times n}$,若 $\operatorname{rank}(B) \le k$,则 $\|A - B\|_2 \ge \sigma_{k+1}$。

由维数公式,$\dim \ker(B) = n - \operatorname{rank}(B) \ge n - k$。令 $S = \operatorname{span}\{v_1, \dots, v_{k+1}\}$,则 $\dim S = k+1$。由子空间维数公式,

$$\dim(S \cap \ker B) = \dim S + \dim \ker B - \dim(S + \ker B) \ge (k+1) + (n-k) - n = 1.$$

故 $S \cap \ker B$ 非零,取 $z \in S \cap \ker B$ 且 $\|z\|_2 = 1$。于是 $B z = 0$,从而

$$\|A - B\|_2 = \max_{\|x\|_2=1} \|(A - B) x\|_2 \ge \|(A - B) z\|_2 = \|A z\|_2.$$

设 $z = c_1 v_1 + \cdots + c_{k+1} v_{k+1}$,则 $c_1^2 + \cdots + c_{k+1}^2 = 1$。由于 $A^T A v_i = \sigma_i^2 v_i$,

$$\|A z\|_2^2 = z^T A^T A z = \sum_{i=1}^{k+1} c_i^2 \sigma_i^2 \ge \sigma_{k+1}^2 \sum_{i=1}^{k+1} c_i^2 = \sigma_{k+1}^2.$$

故 $\|A - B\|_2 \ge \sigma_{k+1}$。

$\square$

定理 1.3.5Weyl 不等式

设 $A, B \in \mathbb{R}^{n \times n}$,则

$$\sigma_{i+j-1}(A + B) \le \sigma_i(A) + \sigma_j(B),$$$$\sigma_{i+j-1}(AB) \le \sigma_i(A) \sigma_j(B).$$

证明. 由低秩逼近定理,存在 $C, D \in \mathbb{R}^{n \times n}$,$\operatorname{rank}(C) \le i-1$,$\operatorname{rank}(D) \le j-1$,使得

$$\|A - C\|_2 = \sigma_i(A), \qquad \|B - D\|_2 = \sigma_j(B).$$

于是

$$\sigma_i(A) + \sigma_j(B) = \|A - C\|_2 + \|B - D\|_2 \ge \|(A + B) - (C + D)\|_2 \ge \sigma_{i+j-1}(A + B),$$

其中最后一步用到 $\operatorname{rank}(C + D) \le i + j - 2$。

同理,

$$\sigma_i(A) \sigma_j(B) = \|A - C\|_2 \|B - D\|_2 \ge \|(A - C)(B - D)\|_2 = \|AB - (AD + CB - CD)\|_2 \ge \sigma_{i+j-1}(AB),$$

其中 $\operatorname{rank}(AD + CB - CD) \le i + j - 2$。

$\square$

命题 1.3.3

设 $A, B \in \mathbb{R}^{m \times n}$,$\operatorname{rank}(B) \le k$,则

$$\sigma_i(A) \ge \sigma_{i+k}(A + B), \qquad i = 1, \dots, n-k.$$

证明. 在 Weyl 不等式中取 $j = k+1$。由于 $\operatorname{rank}(B) \le k$,故 $\sigma_{k+1}(B) = 0$,于是

$$\sigma_{i+k}(A + B) = \sigma_{i+(k+1)-1}(A + B) \le \sigma_i(A) + \sigma_{k+1}(B) = \sigma_i(A).$$

$\square$
