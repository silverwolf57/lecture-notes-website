群、环、域

本章起源:求解一元多项式方程。目的:研究并分类基本代数系统。特点:抽象化、公理化。

4.1 等价关系与商群

4.1.1 陪集与指数

设 $G$ 为群,$H < G$。$\forall\, x, y \in G$,定义 $$x \sim y \iff x^{-1} y \in H.\tag{4.1.1}$$ 易验证这是一个良定义的等价关系。$\forall\, x \in G$,记 $$[x] = \{ y \in G \mid x^{-1} y \in H \} = xH,\tag{4.1.2}$$ 故 $\{xH \mid x \in G\}$ 构成 $G$ 的一个划分。称 $xH$ 为 $H$ 在 $G$ 中的**左陪集**。若 $|H| < \infty$,则映射 $xH \to H$,$xh \mapsto h$ 是双射,故 $|xH| = |H|$。当 $|G| < \infty$ 时,$G$ 被划分为有限个左陪集 $x_1 H, x_2 H, \dots, x_n H$,故 $$|G| = n \cdot |H|.\tag{4.1.3}$$

定义 4.1.1指数

若 $|G| < \infty$,称子群 $H$ 在 $G$ 中左陪集的个数为 $H$ 在 $G$ 中的指数,记作 $[G : H]$。

注记:$|G| = [G : H] \cdot |H|$。同理可定义右陪集 $Hx$,有完全类似的概念与结论。左陪集个数等于右陪集个数,均为指数。

定理 4.1.1Lagrange 定理

设 $G$ 为有限群,$\forall, H < G$,则 $|H| \mid |G|$。

定理 4.1.2

$\forall, a \in G$,若 $|G| < \infty$,则 $\operatorname{ord}(a) \mid |G|$。特别地,$a^{|G|} = e$。若 $|G|$ 为素数,则 $G$ 为循环群。

定理 4.1.3指数的塔律

若 $|G| < \infty$,$K < H < G$,则

$$[G : K] = [G : H] \cdot [H : K].\tag{4.1.4}$$

### 4.1.2 正规子群与商群

现在尝试类似商环定义商群。设 $H < G$,令 $$G / H := \{ gH \mid g \in G \},\tag{4.1.5}$$ 定义乘法 $(g_1 H)(g_2 H) := g_1 g_2 H$。需验证其良定性。 设 $g_1 H = g_1' H$,$g_2 H = g_2' H$,即 $g_1^{-1} g_1' \in H$,$g_2^{-1} g_2' \in H$。需要 $$(g_1 g_2)^{-1} g_1' g_2' = g_2^{-1} g_1^{-1} g_1' g_2' \in H.\tag{4.1.6}$$ 即需要 $g_2^{-1} (g_1^{-1} g_1') g_2 \cdot (g_2^{-1} g_2') \in H$。因此需附加条件:$\forall\, x \in G$,$x^{-1} H x \subseteq H$,即 $x^{-1} H x = H \Leftrightarrow xH = Hx$,即左陪集等于右陪集。

定义 4.1.2正规子群

设 $H < G$,若 $\forall, x \in G$,$xH = Hx$(等价地 $xHx^{-1} = H$),则称 $H$ 为 $G$ 的正规子群,记作 $H \triangleleft G$。

注记:此时左陪集与右陪集相等,统称为 $H$ 的陪集。

例 4.1.1非正规子群的例子

设 $G = S_4$,$H = { (1), (1,2,3), (1,3,2), (1,2)(1,3), (2,3) } \subseteq G$。$H$ 的全部右陪集为 $H, H(1,4), H(2,4), H(3,4)$,全部左陪集为 $H, (1,4)H, (2,4)H, (3,4)H$,且 $(1,4)H \ne H(1,4)$,故左陪集与右陪集不相等,$H$ 不是 $G$ 的正规子群。

定理 4.1.1商群的良定性

设 $H < G$,令 $G / H = {gH \mid g \in G}$。则乘法

$$G / H \times G / H \to G / H,\quad (gH, g’H) \mapsto gg’H\tag{4.1.7}$$ 是良定义的当且仅当 $H \triangleleft G$。此时 $(G / H, \cdot)$ 构成群,称为 $G$ 关于 $H$ 的商群。

### 4.1.3 群同态基本定理

定理 4.1.4正规子群的等价刻画

设 $H < G$,则以下条件等价:

  1. $H \triangleleft G$;

  2. 存在群同态 $\varphi: G \to G’$ 使得 $H = \ker \varphi$;

  3. $\forall, x \in G$,$x^{-1} H x \subseteq H$。

定理 4.1.2群同态基本定理

设 $f: G \to G’$ 为群同态,则 $H = \ker f \triangleleft G$,且存在唯一单同态

$$\bar{f}: G / H \to G’\tag{4.1.8}$$ 使得 $f = \bar{f} \circ \rho$,其中 $\rho: G \to G / H$ 为商同态。

4.2 可解群

4.2.1 单群与可解群的定义

定义 4.2.1单群

没有非平凡正规子群的群称为单群。

定理 4.2.1正规列的存在性

设 $G$ 是非平凡有限群,则存在正规列

$${1} = G_{s+1} \triangleleft G_s \triangleleft G_{s-1} \triangleleft \cdots \triangleleft G_1 = G,\tag{4.2.1}$$ 使得 $G_{i+1} \triangleleft G_i$ 且 $G_i / G_{i+1}$ 为单群。

定义 4.2.2可解群

如果群 $G$ 有正规子群序列

$${1} = G_{s+1} \triangleleft G_s \triangleleft \cdots \triangleleft G_1 = G,\tag{4.2.2}$$ 使得它的因子群 $G_i / G_{i+1}$($1 \le i \le s$)是 Abel 群,则称 $G$ 为可解群。

例 4.2.1$S_4$ 是可解群

考虑正规列

$${1} \triangleleft { (1), (1,2)(3,4) } \triangleleft { (1), (1,2)(3,4), (1,3)(2,4), (1,4)(2,3) } \triangleleft A_4 \triangleleft S_4.\tag{4.2.3}$$ 其中 $A_4$ 为 4 阶交错群,$[S_4 : A_4] = 2$ 故 $A_4 \triangleleft S_4$。上述序列的因子群阶分别为 $2, 3, 2, 2$,均为素数,故均为 Abel 群。因此 $S_4$ 是可解群。

### 4.2.2 换位子群与可解性的刻画

定义 4.2.3中心

群 $G$ 的中心定义为

$$C(G) := { a \in G \mid \forall, x \in G,\ ax = xa }.\tag{4.2.4}$$

定义 4.2.4换位子

$\forall, x, y \in G$,记

$$[x, y] := x^{-1} y^{-1} x y \in G,\tag{4.2.5}$$ 称为 $x, y$ 的换位子。

注记:$C(G) \triangleleft G$。

定义 4.2.5换位子群

群 $G$ 的换位子群定义为

$$G^{(1)} := { [x_1, y_1] \cdots [x_k, y_k] \mid x_i, y_i \in G,\ k \in \mathbb{Z}_{\ge 0} }.\tag{4.2.6}$$ 归纳地,令 $G^{(k)}$ 为 $G^{(k-1)}$ 的换位子群。$G^{(1)} \triangleleft G$。

定理 4.2.1可解群的换位子群刻画

群 $G$ 可解当且仅当存在 $k \ge 1$ 使得 $G^{(k)} = {1}$。

定理 4.2.1可解群的子群、商群与扩张

  1. 如果 $G$ 是可解群,则 $G$ 的任意子群和同态像都是可解群;

  2. 如果 $K \triangleleft G$,且 $K$ 和 $G / K$ 都是可解群,则 $G$ 是可解群。

### 4.2.3 p-群与可解性

定理 4.2.2p-群的中心非平凡

若 $|G| = p^m$($p$ 为素数,$m \ge 1$),则 $p \mid |C(G)|$。

证明. 在 $G$ 上定义共轭关系:$x \sim y \iff \exists, z \in G$ 使 $y = zxz^{-1}$,这是良定义的等价关系。$\forall, x \in G$,其共轭类为 $O_x := {zxz^{-1} \mid z \in G}$。令 $G_x := {z \in G \mid zx = xz}$,则 $G_x < G$。映射 ${zG_x \mid z \in G} \to O_x$,$zG_x \mapsto zxz^{-1}$ 是双射。因此 $|O_x| = [G : G_x] = |G| / |G_x|$。由类方程

$$|G| = |C(G)| + \sum_{|O_x| > 1} |O_x| = p^m,\tag{4.2.7}$$ 且每个 $|O_x| > 1$ 的共轭类满足 $p \mid |O_x|$,故 $p \mid |C(G)|$。$\square$

定理 4.2.2p-群可解

若 $|G| = p^m$($p$ 为素数),则 $G$ 可解。

### 4.2.4 对称群与交错群

定义 4.2.6r-循环

设 $\pi \in S_n$。如果存在 $i_1, i_2, \dots, i_r \in {1, 2, \dots, n}$ 使得

$$\pi(i_1) = i_2,\ \pi(i_2) = i_3,\ \dots,\ \pi(i_{r-1}) = i_r,\ \pi(i_r) = i_1,\tag{4.2.8}$$ 且 $\pi(i) = i$($\forall, i \notin {i_1, \dots, i_r}$),则称 $\pi$ 为一个 r-循环,记作 $(i_1, i_2, \dots, i_r)$。两个循环 $\pi_1 = (i_1, \dots, i_r)$,$\pi_2 = (j_1, \dots, j_s)$ 称为不相交的,如果 ${i_1, \dots, i_r} \cap {j_1, \dots, j_s} = \emptyset$。不相交的循环可交换:$\pi_1 \circ \pi_2 = \pi_2 \circ \pi_1$。

定理 4.2.3置换的循环分解

$S_n$ 中每个置换可唯一分解为一些互不相交的循环之积。

定理 4.2.2置换分解为对换

$S_n$ 中的每个置换可写成若干个长度为 $2$ 的循环(对换)之积。

定义 4.2.7置换的符号

设 $\pi$ 是长度为 $r_1, \dots, r_s$ 的互不相交循环的乘积,则

$$\varepsilon(\pi) := (-1)^{\sum_{i=1}^s (r_i - 1)}\tag{4.2.9}$$ 称为 $\pi$ 的符号。若 $\varepsilon(\pi) = 1$,称 $\pi$ 为偶置换;若 $\varepsilon(\pi) = -1$,称 $\pi$ 为奇置换。

定理 4.2.4符号与对换个数

$\varepsilon(\pi) = 1$ 当且仅当 $\pi$ 可写成偶数个对换之积;$\varepsilon(\pi) = -1$ 当且仅当 $\pi$ 可写成奇数个对换之积。

定义 4.2.8交错群

$S_n$ 中全体偶置换构成的群称为交错群,记作

$$A_n := { \sigma \in S_n \mid \sigma \text{ 为偶置换} }.\tag{4.2.10}$$ 易知 $A_n \triangleleft S_n$,且 $[S_n : A_n] = 2$。

定理 4.2.5$A_n$ 的单性($n \ge 5$)

当 $n \ge 5$ 时,$A_n$ 是单群。特别地,此时 $S_n$ 是不可解群。

4.3 单位根与循环扩张

4.3.1 单位根与单位根群

定义 4.3.1单位根

多项式 $x^n - 1$ 的根称为 n 次单位根。

定义 4.3.2单位根群

设 $K$ 为域,$n > 0$,称

$$U_n(K) := { a \in K \mid a^n = 1 }\tag{4.3.1}$$ 为 $K$ 中的 n 次单位根群。$(U_n(K), \cdot)$ 是一个群。

定理 4.3.1单位根群是循环群

对任意域 $K$ 和任意 $n > 0$,$U_n(K)$ 是循环群。

证明. 取 $\alpha \in U_n(K)$ 使得 $N = \operatorname{ord}(\alpha)$ 最大。下证 $U_n(K) = \langle \alpha \rangle$。

对任意域 $K$,$|U_n(K)| \le n$(因 $x^n - 1 = 0$ 在 $K$ 中至多有 $n$ 个不同的根)。由引理 4.3.1(2),$\forall, y \in U_n(K)$,$y^N = 1$,即 $U_n(K)$ 中元素均为 $x^N - 1 = 0$ 的根。故 $|U_n(K)| \le N = |\langle \alpha \rangle|$。结合 $\langle \alpha \rangle \subseteq U_n(K)$,得 $U_n(K) = \langle \alpha \rangle$。$\square$

定义 4.3.3本原单位根

设 $|U_n(K)| = m$,则称 $U_n(K)$ 的生成元为 m 次本原单位根。

例 4.3.1复数域中的本原单位根

在 $\mathbb{C}$ 中,$\forall, n > 0$,令 $\omega = e^{2\pi i / n}$,则

$$U_n(\mathbb{C}) = { 1, \omega, \omega^2, \dots, \omega^{n-1} },\tag{4.3.2}$$ 故 $n$ 次本原单位根的个数为 $\phi(n)$(Euler 函数)。

### 4.3.2 有限域的结构

设 $K$ 为域,$\operatorname{ch}(K) = p$ 为素数,且 $|K| < \infty$。则 $K$ 的素域为 $\mathbb{F}_p$,且 $K$ 是 $\mathbb{F}_p$ 的有限扩域。设 $[K : \mathbb{F}_p] = n$,则 $|K| = p^n$。令 $K \subseteq L$ 为有限扩张,记 $q = p^n = |K|$。

定义 4.3.4Frobenius 映射

定义映射

$$\eta_q: L \to L,\quad \alpha \mapsto \alpha^q,\tag{4.3.3}$$ 称为 Frobenius 映射。$\eta_q$ 是域同构且 $\eta_q|_K = \operatorname{id}_K$,故 $\eta_q \in \operatorname{Gal}(L / K)$。

定理 4.3.2有限域的结构

设 $p$ 为素数,$n > 0$,$q = p^n$,则:

  1. $f(x) = x^{p^n} - x \in \mathbb{F}_p[x]$ 的分裂域 $\mathbb{F}_q$ 恰有 $q = p^n$ 个元素;

  2. 设 $K$ 是一个 $q = p^n$ 元域,则 $K \cong \mathbb{F}_q$;

  3. 设 $\mathbb{F}_q \subseteq L$ 是 $m$ 次扩张,则 $L = \mathbb{F}_q[\alpha]$ 且 $\operatorname{Gal}(L / \mathbb{F}_q) = \langle \eta_q \rangle$。

### 4.3.3 循环扩张

定义 4.3.5循环扩张

设 $F \subseteq E$ 为有限可分正规扩张。若 $\operatorname{Gal}(E / F)$ 为循环群,则称 $F \subseteq E$ 为循环扩张。

定理 4.3.2循环扩张的刻画

  1. 设 $E = F[\alpha]$,$\alpha^n \in F$。若 $F$ 包含一个 $n$ 次本原单位根 $\theta$,则 $\operatorname{Gal}(E / F)$ 为循环群;

  2. 设 $F \subseteq E$ 是 $n$ 次循环扩张,$F$ 包含一个 $n$ 次本原单位根 $\zeta$,则 $E = F[\alpha]$ 且 $\alpha$ 的极小多项式为 $\mu_\alpha(x) = x^n - a$($a \in F$)。

定理 4.3.3Gauss 定理

对任意 $n > 0$,$\mathbb{C}$ 中任意 $n$ 次本原单位根 $\zeta$ 可由 $\mathbb{Q}$ 经有限次四则运算和开方得到,即 $x^n - 1$ 可用根式解。

4.4 Galois 群的可解性

设 $\operatorname{ch}(K) = 0$,$f(x) \in K[x]$,$\deg f = n$,且 $f(x)$ 无重因子。令 $L$ 为 $f(x)$ 在 $K$ 上的分裂域,则 $$f(x) = c (x - \alpha_1)(x - \alpha_2) \cdots (x - \alpha_n),\quad \alpha_i \in L.\tag{4.4.1}$$ 称 $\operatorname{Gal}(L / K)$ 为 $f(x)$ 的**Galois 群**。每个 $\varphi \in \operatorname{Gal}(L / K)$ 诱导根集合 $\{\alpha_1, \dots, \alpha_n\}$ 上的一个置换,故有单同态 $$\operatorname{Gal}(L / K) \hookrightarrow S_n.\tag{4.4.2}$$ 记其像为 $G_f$,则 $\operatorname{Gal}(L / K) \cong G_f \subseteq S_n$。

4.4.1 Galois 理论基本定理

定理 4.4.1Galois 理论基本定理

设 $K \subseteq L$ 为 Galois 扩张,令 $G = \operatorname{Gal}(L / K)$。记

$$\Gamma = { H \mid H \le G },\quad \Sigma = { E \mid K \subseteq E \subseteq L }.\tag{4.4.3}$$ 则映射

$$\Phi: \Gamma \to \Sigma,\quad H \mapsto L^H = { x \in L \mid \forall, \varphi \in H,\ \varphi(x) = x },\tag{4.4.4}$$

$$\Psi: \Sigma \to \Gamma,\quad E \mapsto \operatorname{Gal}(L / E)\tag{4.4.5}$$ 是互逆的双射,且满足:

  1. $H_1 \supseteq H_2 \iff L^{H_1} \subseteq L^{H_2}$;

  2. $|H| = [L : L^H]$,$[G : H] = [L^H : K]$;

  3. $H \triangleleft G \iff K \subseteq L^H$ 为正规扩张,此时 $\operatorname{Gal}(L^H / K) \cong G / H$。

### 4.4.2 方程可解性的 Galois 判别

定理 4.4.2Galois 理论主要定理

设 $\operatorname{ch}(K) = 0$,$f(x) \in K[x]$ 无重因子,则

$$f(x) = 0 \text{ 可用根式解} \iff f(x) \text{ 的 Galois 群可解}.\tag{4.4.6}$$

**备注(可解群的素数阶循环列刻画)**:群 $G$ 可解当且仅当存在子群列 $$\{e\} = G_1 \triangleleft G_2 \triangleleft \cdots \triangleleft G_r = G,\tag{4.4.7}$$ 使得每个商群 $G_{k+1} / G_k$ 为素数阶循环群。

定理 4.4.1Galois 群可解 $\Rightarrow$ 方程可解

若 $f(x)$ 的 Galois 群可解,则 $f(x) = 0$ 可用根式解。

证明. 设 $L$ 为 $f(x)$ 在 $K$ 上的分裂域,令 $m = [L : K]$,取 $m$ 次本原单位根 $\zeta$。记 $K_1 = K[\zeta]$,$L_1 = L[\zeta]$,则 $L_1$ 是 $f(x)$ 在 $K_1$ 上的分裂域。因 $\operatorname{ch}(K) = 0$,$K_1 \subseteq L_1$ 为 Galois 扩张。定义限制映射

$$\pi: \operatorname{Gal}(L_1 / K_1) \to \operatorname{Gal}(L / K),\quad \varphi \mapsto \varphi|_L.\tag{4.4.8}$$ 可证 $\pi$ 是单同态,故 $\operatorname{Gal}(L_1 / K_1)$ 同构于 $\operatorname{Gal}(L / K)$ 的子群,故可解。

由可解群的素数阶循环列刻画,存在

$${e} = G_1 \triangleleft G_2 \triangleleft \cdots \triangleleft G_r = \operatorname{Gal}(L_1 / K_1),\tag{4.4.9}$$ 使得每个 $G_{k+1} / G_k$ 为素数阶循环群。由 Galois 理论基本定理,对应中间域链

$$L_1 \supseteq L_1^{G_2} \supseteq \cdots \supseteq L_1^{G_r} = K_1.\tag{4.4.10}$$ 每个 $G_k / G_{k-1}$ 为素数阶循环群,故对应的扩张 $L_1^{G_k} \subseteq L_1^{G_{k-1}}$ 为循环扩张。设其次数为 $p_k$,则 $p_k \mid |\operatorname{Gal}(L_1 / K_1)| \mid m$。因 $K_1$ 包含 $m$ 次本原单位根,故也包含 $p_k$ 次本原单位根。由引理 4.3.2(2),每个循环扩张可由添加 $p_k$ 次根得到。因此 $L_1$(从而 $L$)可由 $K$ 经有限次四则运算和开方得到,即 $f(x) = 0$ 可用根式解。$\square$

定理 4.4.2方程可解 $\Rightarrow$ Galois 群可解

若 $f(x) = 0$ 可用根式解,则 $f(x)$ 的 Galois 群可解。
