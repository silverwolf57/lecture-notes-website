MATH 201 线性代数 · 第 1 讲

向量、矩阵与线性映射

本讲建立后续所有内容的记号与几何直觉。我们从 $\mathbb{R}^n$ 出发,把矩阵看作线性映射,把"线性"二字理解成"保持加法与数乘",并由此推出矩阵乘法的几何意义。

1. 向量空间与子空间

定义 1.1向量空间

实向量空间 $(V, +, \cdot)$ 是一个集合 $V$,配备加法 $+$ 与数乘 $\cdot$,满足八条公理:交换律、结合律、零元、负元、数乘单位、数乘结合律、左右分配律。我们几乎只在 $V = \mathbb{R}^n$ 上工作。

$\mathbb{R}^n$ 中由向量 $v_1, \ldots, v_k$ 张成的子空间是 $$\mathrm{span}(v_1, \ldots, v_k) = \left\{ \sum_{i=1}^{k} \alpha_i v_i \;\middle|\; \alpha_i \in \mathbb{R} \right\}.$$ 这是一个最小闭子空间:任何包含 $\{v_i\}$ 的子空间必包含 $\mathrm{span}\{v_i\}$。

2. 矩阵作为线性映射

设 $A \in \mathbb{R}^{m \times n}$。映射 $x \mapsto Ax$ 是 $\mathbb{R}^n \to \mathbb{R}^m$ 的线性映射;反过来,任何线性映射在选定基后都唯一对应一个矩阵。这一对应是范畴论中 $$\mathrm{Hom}_{\mathbb{R}}(\mathbb{R}^n, \mathbb{R}^m) \cong \mathbb{R}^{m \times n}$$ 的具体表现。

2.1 矩阵乘法的几何读法

把 $A$ 拆成列 $A = [a_1 \; a_2 \; \cdots \; a_n]$,则 $$Ax = x_1 a_1 + x_2 a_2 + \cdots + x_n a_n,$$ 即 $Ax$ 是诸列以 $x$ 的分量为系数的线性组合。换言之,$A$ 的第 $j$ 列就是 $e_j$ 在映射下的像。

定理 1.2秩-零化度定理

对任意 $A \in \mathbb{R}^{m \times n}$, $$\dim \mathrm{Im}(A) + \dim \ker(A) = n.$$

证明要点:取 $\ker A$ 的一组基,扩充为 $\mathbb{R}^n$ 的基;后者在 $A$ 下的像构成 $\mathrm{Im} A$ 的一组基。

3. 四个基本子空间

对任意 $A \in \mathbb{R}^{m \times n}$,下列四个子空间刻画了 $A$ 的所有几何信息:

  • $\mathrm{Col}(A) = \{Ax : x \in \mathbb{R}^n\} \subseteq \mathbb{R}^m$ — 列空间,秩为 $\mathrm{rank}\,A$。
  • $\mathrm{Null}(A) = \{x : Ax = 0\}$ — 零空间,维数为 $n - \mathrm{rank}\,A$。
  • $\mathrm{Row}(A) = \mathrm{Col}(A^\top) \subseteq \mathbb{R}^n$ — 行空间。
  • $\mathrm{Null}(A^\top) = \{y : A^\top y = 0\}$ — 左零空间。

4. 一个应用:最小二乘

给定超定方程组 $Ax = b$($A$ 列满秩,$m > n$)。最小二乘解定义为 $$x^{\star} = \arg\min_{x \in \mathbb{R}^n} \|Ax - b\|_2^2.$$ 求导并令其为零,得 $$A^\top A x^{\star} = A^\top b.$$ 这就是正规方程。当 $A$ 列满秩时 $A^\top A$ 可逆,故 $x^{\star} = (A^\top A)^{-1} A^\top b$。

练习 1.1

用 NumPy 实现上述求解,并对比 numpy.linalg.lstsq 的结果:

import numpy as np
A = np.array([[1, 1], [1, 2], [1, 3]], dtype=float)
b = np.array([1.0, 2.0, 2.0])
x_normal = np.linalg.solve(A.T @ A, A.T @ b)
x_lstsq, *_ = np.linalg.lstsq(A, b, rcond=None)
print(np.allclose(x_normal, x_lstsq))  # True
